# Troubleshooting WSA App Uninstallation Issues

When an Android app is uninstalled from Windows Subsystem for Android (WSA), it may still show up in the Windows "All apps" list or Start Menu. 

## Symptoms of a "Ghost" App:
*   The app still appears in the WSA "Apps" list.
*   Clicking the app or its settings results in nothing happening, or a small popup window appearing and immediately closing.
*   The Android package is gone, but the Windows registration remains.

## Why this happens:
1.  **Registry Entries:** Windows stores app registrations and protocol handlers in the registry.
2.  **Uninstall Registry:** Windows keeps a record of the app in its "Uninstall" list, which is often what drives the WSA "Apps" list.
3.  **Icon Cache:** The WSA app manager keeps PNG/ICO files in its `LocalState` directory.
4.  **Shortcuts:** Windows creates `.lnk` files in your Start Menu. If you manually dragged these to your **Desktop**, those shortcuts will also remain.

## Steps to Manually Resolve:

### 1. Identify the Package Name
Find the package name of the app you uninstalled. 
```bash
adb shell pm list packages -u
```
Example: `com.android.vending` (Play Store) or `com.fidloo.cinexplore` (Cinexplore).

### 2. Remove Registry Keys (Two Locations)

#### A. Classes & Protocol Handlers
Search for the app's internal WSA ID under:
`HKEY_CURRENT_USER\Software\Classes\`
Look for keys starting with `wsa.` (e.g., `wsa.c1cfae2eb5a6ac9e`). Check the `ApplicationName` inside to confirm.

#### B. Uninstall Entry (Crucial for the App List)
Navigate to:
`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Uninstall\`
Look for a key named exactly like the Android package (e.g., `com.android.vending`). Delete this key to remove it from the WSA app list.

### 3. Remove Shortcuts (Start Menu & Desktop)
*   **Start Menu:** `%APPDATA%\Microsoft\Windows\Start Menu\Programs`
*   **Desktop:** Check your Desktop for any shortcuts you manually added for the app and delete them.

### 4. Clear LocalState Cache
Navigate to:
`%LOCALAPPDATA%\Packages\MicrosoftCorporationII.WindowsSubsystemForAndroid_8wekyb3d8bbwe\LocalState`
Delete any `.ico` or `.png` files that match the app's package name.

### 5. Refresh Windows Shell
If the app still appears, restart "Windows Explorer" in Task Manager or run:
```powershell
Get-Process explorer | Stop-Process
```
