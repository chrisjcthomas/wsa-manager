# Docs Index

Use this directory in two ways:

- Active design references:
  - `docs/code.html`
  - `docs/screen.png`
- Historical reference only:
  - `docs/archive/`

## Current Source Of Truth

For the live project workflow, use:

- `AGENTS.md`
- `README.md`
- `docs/README.md`
- `.github/pull_request_template.md`

These files define the active build, test, PR, release, and review process.

## Archive

`docs/archive/` contains older planning notes, manual cleanup guidance, and one-off helper scripts from before the repo workflow was formalized.

Keep those files for context, but do not treat them as the current product or workflow spec.
